About This Page

This Application

This web application is a full-stack web app that uses React for the frontend and Node.js with Express for the backend. The backend exposes a RESTful API that allows the frontend to perform operations such as retrieving, creating, updating, and deleting artworks. On the frontend, Axios is used to make asynchronous HTTP requests (commonly referred to as AJAX) to this API without requiring page reloads, enabling a smooth and interactive user experience. The data is stored using MongoDB, and for development purposes, an in-memory MongoDB instance (via MongoMemoryServer) is used, meaning data resets on every server restart. The page you are viewing right now is a static HTML file served directly by the Express server, providing technical and conceptual insights about the application. Overall, this system is designed as a simple CRUD (Create, Read, Update, Delete) application for managing a collection of artworks in a modern single-page architecture.

Technologies Used

ReactJS (Frontend)
Node.js (Server Runtime)
ExpressJS (Backend Framework)
MongoDB / MongoMemoryServer (Database)
Axios (AJAX Requests)
Bootstrap (Styling & Layout)

Weaknesses

  • DATA PERSISTENCY – Data is not persistent (in-memory MongoDB resets on restart). This leads to slower boot times.
  • AUTHENTICATION – No authentication or admin panel. Anybody can perform top-level actions.
  • IMAGE UPLOADING – Must be provided via URL. Finding image URLs can be difficult for non-technical users.

Alternative Approaches

  • Use MongoDB Atlas or a local MongoDB for persistent storage
  • Integrate Cloudinary or local file uploads for image handling
  • Use a WYSIWYG editor (like Quill.js) for rich text input
  • Add user authentication using JWT or session-based logins
